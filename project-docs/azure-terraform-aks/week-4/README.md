# Week 4 Incident Response and Day-2 Operations

Goal: run repeatable incident handling and operations workflows.

## Daily Plan

1. Day 1: Controlled failure injection (pod crash, bad rollout)
2. Day 2: DNS and dependency failure simulation
3. Day 3: Capacity pressure simulation and response
4. Day 4: Runbook validation and post-incident write-up
5. Day 5: SLO and error budget review

## Exit Criteria

- You can run a calm, step-by-step incident response
- Rollback and recovery are fast and repeatable
- Runbooks are tested and reflect reality
- You can map incidents to SLO impact
