# Week 3 Observability and Alerting

Goal: build practical monitoring and alerting workflows.

## Daily Plan

1. Day 1: Metrics and logs data-path validation
2. Day 2: Dashboard creation (golden signals)
3. Day 3: Alert rule design and thresholds
4. Day 4: Correlation workflow (alert -> logs -> root cause)
5. Day 5: Noise reduction and alert quality review

## Golden Signals

- Latency
- Traffic
- Errors
- Saturation

## Exit Criteria

- You can detect and triage common service failures quickly
- Dashboards and alerts are actionable, not noisy
- You can correlate metrics and logs during incident drills
