# Week 1 Kubernetes Foundations

Goal: become fluent with core workload operations in AKS.

## Daily Plan

1. Day 1: Namespaces and Deployments
2. Day 2: Services and Ingress basics
3. Day 3: Health probes (readiness/liveness/startup)
4. Day 4: Rollouts and rollbacks
5. Day 5: Resource requests and limits

## Exit Criteria

By end of Week 1 you can:

- Create and isolate workloads by namespace
- Deploy and scale workloads confidently
- Perform rollout status checks and rollback quickly
- Explain basic pod lifecycle and health checks

## Evidence Checklist

- Namespace inventory screenshot/output
- Deployment history and rollout output
- At least one successful rollback
- Notes on one failure case and fix
