# Week 2 Reliability and Platform Patterns

Goal: improve workload resilience and operational safety.

## Daily Plan

1. Day 1: Horizontal Pod Autoscaler (HPA)
2. Day 2: PodDisruptionBudget and node drain behavior
3. Day 3: NetworkPolicy allow/deny patterns
4. Day 4: ConfigMap and Secret lifecycle operations
5. Day 5: Failure simulation and recovery checklist

## Exit Criteria

- You can explain and tune autoscaling behavior
- You can prevent unsafe disruptions during maintenance
- You can enforce network boundaries between workloads
- You can safely externalize config and secret data
